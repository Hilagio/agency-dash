### Purpose

This catalog lists all available Google Ads extension types with their specifications, vertical fit, and example content. It supports creative execution by providing a reference for expanding ad "real estate" and click options.

---

### What this is / What this is NOT

**This catalog:**

- Enumerates extension types and their specifications
- Provides examples organized by vertical (Lead Gen, SaaS, Ecommerce)
- Describes vertical fit for each extension type

**This catalog does NOT:**

- Validate extension coverage (see: [Extension Coverage Checklist](../checklists/Extension Coverage Checklist.md))
- Prescribe automated asset settings (see: [Automated Assets Control Guidelines](../guidelines/Automated Assets Control Guidelines.md))
- Provide step-by-step execution instructions

---

### Extension types overview

| Extension | Purpose | Clickable | Quantity |
| --- | --- | --- | --- |
| **Sitelinks** | Direct links to specific pages | Yes | 4-8 |
| **Callouts** | Non-clickable benefit highlights | No | 4-8 |
| **Structured Snippets** | Categorized feature lists | No | 2-4 headers |
| **Image** | Visual product/service imagery | No | 1-20 |
| **Business Name** | Brand name display | No | 1 |
| **Business Logo** | Logo image | No | 1 |
| **Promotion** | Sales, discounts, offers | Yes | As needed |
| **Price** | Service/product pricing | Yes | 3-8 items |
| **Call** | Phone number | Yes | 1 |
| **Location** | Physical address | Yes | As needed |
| **Lead Form** | In-ad form submission | Yes | 1 |
| **Message** | Direct to messaging platforms | Yes | 1 |
| **App** | Mobile app promotion | Yes | 1 |

## 1️⃣ Sitelinks

### Purpose

Additional click targets to specific pages, acting as secondary navigation within the ad.

### Specs

| Element | Limit |
| --- | --- |
| Link text | 25 characters |
| Description 1 | 35 characters |
| Description 2 | 35 characters |
| Quantity | 4-8 recommended |

**Note:** Descriptions don't always show. Link text must stand alone.

### Best fit by vertical

| Vertical | Fit | Notes |
| --- | --- | --- |
| Lead Gen | High | Service pages, case studies, contact |
| SaaS | High | Pricing, demo, trial, integrations |
| Ecommerce | High | Categories, shipping, reviews |

### Examples

#### Lead Gen:

| Link Text | Description 1 | Description 2 |
| --- | --- | --- |
| "Free Marketing Audit" | "Get your custom report in 48hrs". | "See what's working and what's not". |
| "View Case Studies" | "Real results from real clients". | "See how we drove 40% more leads". |
| "Pricing & Packages" | "Transparent pricing, no surprises". | "Month-to-month available". |
| "Book a Call" | "Free 30-min strategy session". | "No obligation, just insights". |

#### SaaS:

| Link Text | Description 1 | Description 2 |
| --- | --- | --- |
| "Start Free Trial" | "No credit card required". | "Full access for 14 days". |
| "See Pricing" | "Plans for teams of all sizes". | "Free plan available forever". |
| "Watch Demo" | "See the platform in action". | "Just 5 minutes, no signup". |
| "Integrations" | "Connect with 50+ tools". | "Slack, Salesforce, HubSpot & more". |

#### Ecommerce:

| Link Text | Description 1 | Description 2 |
| --- | --- | --- |
| "Shop All Sofas" | "Browse our full collection". | "100+ styles and configurations". |
| "Free Fabric Samples" | "Feel the quality first". | "Delivered free in 3 days". |
| "Delivery Info" | "Free shipping over €500". | "White-glove assembly included". |
| "Customer Reviews" | "4.7/5 from 8,400 reviews". | "See what customers say". |

### Quality notes

- Link text: clear, action-oriented, specific (not "Learn More")
- Descriptions: add value, don't repeat link text
- URLs: relevant, functional pages
- No duplicate messaging with RSA headlines

## 2️⃣ Callouts

### Purpose

Short, non-clickable phrases highlighting key benefits or features. Appear as a single line below descriptions.

### Specs

| Element | Limit |
| --- | --- |
| Callout text | 25 characters |
| Quantity | 4-8 recommended |

**Note:** Google shows 2-6 callouts in a row.

### Best fit by vertical

| Vertical | Fit | Notes |
| --- | --- | --- |
| Lead Gen | High | Trust signals, service differentiators |
| SaaS | High | Features, security, flexibility |
| Ecommerce | High | Shipping, returns, warranties |

### Examples

#### Lead Gen:

| Callout | Chars | Category |
| --- | --- | --- |
| "Free Initial Consultation" | 25 | Value |
| "No Long-Term Contracts" | 22 | Risk |
| "Dedicated Account Manager" | 25 | Service |
| "Google Premier Partner" | 22 | Trust |
| "Results in 30 Days" | 18 | Speed |
| "Transparent Reporting" | 21 | Service |
| "Senior Experts Only" | 19 | Trust |
| "Month-to-Month Billing" | 22 | Flexibility |

#### SaaS:

| Callout | Chars | Category |
| --- | --- | --- |
| "Free Plan Available" | 19 | Value |
| "No Credit Card Needed" | 21 | Risk |
| "Setup in 2 Minutes" | 18 | Speed |
| "24/7 Live Support" | 17 | Service |
| "50+ Integrations" | 16 | Features |
| "Mobile App Included" | 19 | Features |
| "Cancel Anytime" | 14 | Risk |
| "SOC 2 Certified" | 15 | Trust |
| "Unlimited Users" | 15 | Value |
| "GDPR Compliant" | 14 | Trust |

#### Ecommerce:

| Callout | Chars | Category |
| --- | --- | --- |
| "Free Shipping Over €50" | 22 | Value |
| "Easy 60-Day Returns" | 19 | Risk |
| "10-Year Warranty" | 16 | Trust |
| "Delivered Assembled" | 19 | Convenience |
| "100+ Fabric Options" | 19 | Features |
| "Price Match Guarantee" | 21 | Value |
| "Same-Day Dispatch" | 17 | Speed |
| "Handmade in Europe" | 18 | Trust |
| "Klarna Available" | 16 | Convenience |
| "Rated 4.7/5 Stars" | 17 | Trust |

### Quality notes

- Each callout: distinct benefit (no repetition)
- Mix categories: trust, value, speed, features, risk
- Promotional language belongs in Promotion extension
- Visual enhancement: prefix with "+" for prominence

> 💡 **A leading plus sign makes a callout pop.** Bob prefixes each callout with `+` for prominence in the served ad.

## 3️⃣ Structured snippets

### Purpose

Categorized list of offerings, helping searchers quickly understand what is provided.

### Specs

| Element | Limit |
| --- | --- |
| Header | Predefined options only |
| Values | 25 characters each |
| Values per header | 3-10 recommended |

**Available headers:**

- Amenities
- Brands
- Courses
- Degree programs
- Destinations
- Featured hotels
- Insurance coverage
- Models
- Neighborhoods
- Service catalog
- Shows
- Styles
- Types

### Best fit by vertical

| Vertical | Fit | Best Headers |
| --- | --- | --- |
| Lead Gen | High | Service catalog, Types |
| SaaS | High | Types, Amenities |
| Ecommerce | High | Styles, Types, Brands |

### Examples

#### Lead Gen:

| Header | Values |
| --- | --- |
| Service catalog | Google Ads, Facebook Ads, SEO, Landing Pages, Analytics, CRO |
| Types | PPC Management, Consulting, Audits, Training, Strategy |

#### SaaS:

| Header | Values |
| --- | --- |
| Types | Pipeline Management, Contact Database, Email Sequences, Reporting |
| Amenities | API Access, Mobile Apps, Integrations, Automations, Templates |

#### Ecommerce:

| Header | Values |
| --- | --- |
| Styles | Modern, Scandinavian, Mid-Century, Industrial, Minimalist |
| Types | Sofas, Sectionals, Armchairs, Coffee Tables, Bed Frames |

### Quality notes

- Header must accurately categorize values
- Values: specific, not generic
- Minimum 4 values per header recommended

## 4️⃣ Image extensions

### Purpose

Visual elements added to text ads, increasing engagement and helping searchers visualize products or services.

### Specs

| Element | Requirement |
| --- | --- |
| Aspect ratio | 1:1 required, 1.91:1 optional |
| Minimum size | 300×300 (1:1), 600×314 (1.91:1) |
| Recommended size | 1200×1200 (1:1), 1200×628 (1.91:1) |
| File size | Max 5MB |
| File type | PNG, JPG, GIF (static) |
| Quantity | 1-20 images |

### Best fit by vertical

| Vertical | Fit | Best Image Types |
| --- | --- | --- |
| Lead Gen | Medium | Team photos, results visualizations, certifications |
| SaaS | High | Product screenshots, dashboard views, mobile app |
| Ecommerce | High | Product shots, lifestyle images, detail shots |

### Examples

**Lead Gen:** Team photo, office/workspace, results charts, client logos, certification badges

**SaaS:** Clean UI screenshot, dashboard view, mobile app, integration logos, benefit illustrations

**Ecommerce:** Hero product shot, lifestyle image, multiple angles, detail shots, scale reference

### Notes

- High-resolution (1200×1200 minimum)
- Simple and clear, product/service visible
- No excessive text overlay
- Matches the ad's message
- Multiple images for Google to test

### Purpose

Brand recognition and trust at a glance.

### Specs

#### Business Name:

| Element | Limit |
| --- | --- |

**Rules:** Must match legal/DBA name, no promotional language, no phone/URLs, proper capitalization.

#### Logo:

| Element | Requirement |
| --- | --- |
| Aspect ratio | 1:1 (square) |
| Minimum size | 128×128 pixels |
| Recommended size | 1200×1200 pixels |
| File type | PNG, JPG |
| Background | Transparent or solid |

### Best fit by vertical

| Vertical | Fit | Notes |
| --- | --- | --- |
| All | High | Foundational brand element |

### Quality notes

- Official logo version only
- Legible at small sizes
- High contrast (not white on white)
- Consistent with current brand

## 6️⃣ Promotion extensions

### Purpose

Highlight special offers, sales, and discounts with dedicated formatting.

### Specs

| Element | Options/Limits |
| --- | --- |
| Occasion | None, New Year, Valentine's, Black Friday, etc. |
| Promotion type | Monetary discount, Percent discount, Up to monetary, Up to percent |
| Item | 20 characters |
| Final URL | Landing page for offer |
| Dates | Optional start/end dates |

### Best fit by vertical

| Vertical | Fit | Notes |
| --- | --- | --- |
| Lead Gen | Medium | First month discounts, package deals |
| SaaS | High | Trial offers, annual discounts |
| Ecommerce | High | Sales, seasonal promotions |

### Examples

#### Lead Gen:

| Occasion | Type | Details | Item |
| --- | --- | --- | --- |
| None | Monetary | €500 off | First Month |
| None | Percent | 20% off | Audit Package |

#### SaaS:

| Occasion | Type | Details | Item |
| --- | --- | --- | --- |
| None | Percent | 50% off | First 3 Months |
| None | Percent | 20% off | Annual Plans |

#### Ecommerce:

| Occasion | Type | Details | Item |
| --- | --- | --- | --- |
| None | Percent | 15% off | First Order |
| Black Friday | Up to percent | Up to 50% off | Select Sofas |

### Quality notes

- A limited-time offer needs both the promotion dates and asset scheduling set
- The landing page has to reflect the promotion

> 💡 **Promotion dates alone do not stop the asset from serving.** A limited-time promotion needs the promotion **start** and **end date** plus the **asset schedule** (under "advanced options"). Without the schedule the asset keeps showing after the promotion has elapsed.

## 8️⃣ Call extensions

### Purpose

Clickable phone number enabling direct calls (especially valuable on mobile).

### Specs

| Element | Requirement |
| --- | --- |
| Phone number | Valid, callable number |
| Call reporting | Optional |
| Schedule | Optional (set business hours) |

### Best fit by vertical

| Vertical | Fit | Notes |
| --- | --- | --- |
| Lead Gen (services) | High | Phone leads often higher intent |
| Lead Gen (B2B) | Variable | Depends on sales process |
| SaaS | Low | Usually prefer trial signups |
| Ecommerce | Variable | High-consideration purchases only |
| Local services | High | Immediate booking/quotes |

### Quality notes

- The schedule covers only the hours when calls can be answered
- Call reporting tracks calls, and call recording where available (US/CA) lets AI qualification count call conversions by lead quality instead of the raw duration threshold
- An import calls conversion action qualifies calls from a CRM or call system, and own data beats any proxy

## 9️⃣ Location extensions

### Purpose

Show physical addresses, helping local searchers find businesses and adding trust.

### Specs

| Element | Requirement |
| --- | --- |
| Google Business Profile | Linked and verified |
| Locations | One or more verified |

### Best fit by vertical

| Vertical | Fit | Notes |
| --- | --- | --- |
| Local services | High | Drives store visits |
| Ecommerce with showrooms | High | Enables try-before-buy |
| Pure-play ecommerce | Low | No physical location benefit |
| SaaS | Low | Unless enterprise with offices |
| National services | Variable | Can build trust but may confuse |

### Quality notes

- Worth adding only when a physical location is part of the customer journey

## 🔟 Lead Form extensions

### Purpose

In-ad form submission without visiting landing page.

### Specs

| Element | Options |
| --- | --- |
| Fields | Name, Email, Phone, Postal Code, Company, Job Title, Work Email, Work Phone |
| Questions | Custom qualifying questions (optional) |
| CTA | Predefined options |
| Background image | Optional |

### Best fit by vertical

| Vertical | Fit | Notes |
| --- | --- | --- |
| Lead Gen | High | Lower friction, higher volume |
| SaaS | Medium | May reduce qualification |
| Ecommerce | Low | Not typical use case |

### Quality notes

- Trade-off: higher volume, lower quality
- Less brand experience than landing page
- Works well on slow connections

## 1️⃣1️⃣ Message assets

### Purpose

Button directing users to messaging platforms (WhatsApp, Messenger, Zalo).

### Specs

| Element | Requirement |
| --- | --- |
| Platforms | WhatsApp, Facebook Messenger, Zalo |
| Starter message | Custom message |
| Campaign types | Search, Performance Max |

#### Platform setup:

| Platform | Required Input | Format Example |
| --- | --- | --- |
| WhatsApp | Phone number (with country) | Active WhatsApp Business number |

**Requirements:** Good policy compliance history, completed Advertiser Verification, eligible vertical.

### Best fit by vertical

| Vertical | Fit | Notes |
| --- | --- | --- |
| Local services | High | Quick quotes, appointment booking |
| Ecommerce (high-touch) | High | Pre-purchase questions, custom orders |
| Lead Gen | High | Conversational lead capture |
| SaaS | Low | Usually prefer trial/demo signups |
| Low-consideration ecommerce | Low | Adds friction |

### Quality notes

- Availability depends on the account meeting the requirements above
- Naming the messaging platform in a headline causes confusion

## 1️⃣2️⃣ App assets

### Purpose

Promote mobile app alongside ads, driving downloads or engagement.

### Specs

| Element | Requirement |
| --- | --- |
| App store | Google Play or Apple App Store |
| Link type | Download or deep link |
| Campaign types | Search, Display, Performance Max |

### Best fit by vertical

| Scenario | Fit | Notes |
| --- | --- | --- |
| Mobile app is core product | High | Direct path to download |
| App enhances web experience | Variable | May distract from primary conversion |
| App is secondary to web | Test first | Cannibalizes higher-value web conversions |

### Quality notes

- App installs compete with higher-value web actions, so the install has to be the goal itself

## Common extension misuse patterns

| Mistake | Example | Fix |
| --- | --- | --- |
| **Duplicate messaging** | RSA + callout both say "Free Trial" | Use callouts for benefits NOT in headlines |
| **Generic sitelinks** | "Learn More", "Click Here" | Be specific: "See Pricing", "Read Case Studies" |
| **Missing descriptions** | Sitelinks without descriptions | Always add descriptions (even if they don't always show) |
| **Low-quality images** | Blurry product photos | Invest in high-res imagery |
| **Outdated promotions** | "Black Friday Sale" in January | Set end dates, audit monthly |
| **Too few extensions** | Only 2 sitelinks, 2 callouts | Add 4-8 of each to give Google optimization options |
| **Wrong extensions for vertical** | Call extensions for SaaS with no sales team | Match extensions to customer journey and vertical |
| **Leaving automated assets on** | Auto-generated sitelinks conflicting with manual ones | Turn off automated assets when manual assets perform better |
