## Purpose

This catalog lists reusable **description expansion patterns** that reinforce headlines without repetition. It supports creative execution by providing options for expanding a message into 75-90 character descriptions.

---

## What this catalog is / What this is NOT

**This catalog:**

- Lists description "expansion" patterns by angle and by combination
- Provides example descriptions by vertical (Lead Gen, SaaS, Ecommerce)
- Includes key constraints (character count, keyword bolding behavior)

**This catalog does NOT:**

- Validate description quality or completeness (see: [Description Quality Checklist](../checklists/Description Quality Checklist.md))
- Prescribe how many descriptions to run or what to test next (that belongs to SOPs)
- Provide step-by-step execution instructions
- Teach dynamic text setup (see: [Dynamic Text Reference](../references/Dynamic Text Reference.md) )

---

## Core constraints

### Character limit

- **Max:** 90 characters
- **Recommended:** 75-90 characters

### Non-duplication rule

Descriptions should **add new information** beyond headlines (context, proof, specifics, reassurance).

### Query bolding behavior

Google bolds text that matches the user's search query. One natural inclusion of the core phrase in at least one description often increases visual prominence.

## Static vs. Dynamic: Decision gate

Before writing descriptions, determine your approach:

| If … | Then use … | Reference |
| --- | --- | --- |
| Messaging rarely changes | Static description | This catalog |
| Price/discount/promo changes | Ad Customizers | [Dynamic Text Reference](../references/Dynamic Text Reference.md) |
| Product name varies by keyword | Keyword-level Customizers | [Dynamic Text Reference](../references/Dynamic Text Reference.md) |
| Time-limited offer with real deadline | Countdown Timer | [Dynamic Text Reference](../references/Dynamic Text Reference.md) |
- → **For syntax, rules, and setup:**
    - See [Dynamic Text Reference](../references/Dynamic Text Reference.md)
- → **For dynamic customizer attributes (price, inventory, promos):**
    - See [Dynamic Ad Customizer Attribute Catalog](../catalogs/Dynamic Ad Customizer Attribute Catalog.md)

> 💡 **Descriptions have more room for dynamic combinations:** With 90 characters, you can combine multiple customizers in one description. This is especially powerful for Ecommerce.

## Two expansion approaches

### 1️⃣ Single-angle expansion

One description focuses on one message job (e.g., proof, risk removal, value).

### 2️⃣ Combined-angle expansion

One description stacks 2–3 message jobs (e.g., Benefit + Proof, Proof + CTA) to maximize density.

## A. Single-angle description patterns

### 1️⃣ Problem / Pain Recognition

**Job:** Mirror the searcher's frustration and bridge to the solution.

**Pattern templates:**

- `[Tired of X?] + [We solve it]`
- `[Pain] + [What you get instead]`
- `[Symptom] + [Outcome]`
