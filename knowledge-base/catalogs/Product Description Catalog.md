### Purpose

This catalog lists reusable **product description formulas and patterns** used to optimize Shopping feed descriptions for maximum query matching and conversion.

Product descriptions serve two purposes: helping Google match your products to relevant queries (secondary matching signal) and providing information to users on the Shopping tab. This catalog provides templates and examples for effective descriptions.

## Description fundamentals

### Character limits and visibility

| **Context** | **Visibility** | **Implication** |
|-------------|---------------|-----------------|
| Shopping tab (visible) | First 160 characters | Front-load key info |
| Full description | 5000 max | Include all relevant keywords |
| Product Listing Ad | Not shown | Used for matching only |

### Description principles

- **Front-load** key features in first 160 characters
- **Include** relevant attributes (material, color, size, features, benefits)
- **Be specific** rather than generic
- **Use natural language** with relevant keywords
- **No promotional text** (causes disapprovals)

> 💡 **Descriptions are a secondary matching signal.** Titles carry more weight. A well-optimized description adds relevant queries the title alone would miss.

## The core description formula

**Universal formula:**

`[Brand] presents [product], perfect for [target audience] who [user's need or desire]. This [product type] features [key feature 1], [key feature 2], and [key feature 3], making it [unique selling proposition].`

This formula ensures you cover:
1. Brand and product identification
2. Target audience
3. Key features and specifications
4. Value proposition

## Category-specific templates

### Fashion / Apparel

**Template:**
```
Elevate your style with the [Brand] [Product Name]. This [product type] is designed for [target audience] who value [quality/comfort/style]. Made from [material], it features [feature 1], [feature 2], and [feature 3]. The [color] colorway pairs perfectly with [styling suggestion]. Available in size [size], it offers [fit type] fit for [comfort/mobility].
```

**Example:**
"Elevate your running performance with the Nike Air Zoom Pegasus 40 Women's Running Shoes. Designed for everyday runners who value comfort and responsiveness, these shoes feature Nike React foam cushioning, a breathable mesh upper, and a durable rubber outsole. The Black/White colorway pairs perfectly with any athletic wear. Available in size 8, they offer a true-to-size fit for all-day comfort during training runs and casual wear".

### Electronics

**Template:**
```
Experience [benefit] with the [Brand] [Product Name]. This [product type] delivers [key spec 1], [key spec 2], and [key spec 3]. Perfect for [use case], it features [feature 1] for [benefit 1] and [feature 2] for [benefit 2]. Compatible with [compatibility], this [product type] includes [what's in box]. The [color] finish complements any setup.
```

**Example:**
"Experience superior memory performance with the Corsair Vengeance RGB Pro 32GB DDR4 RAM. This desktop memory kit delivers 3200MHz speed, low latency timing, and dynamic RGB lighting. Perfect for gaming and content creation, it features aluminum heat spreaders for optimal cooling and Intel XMP 2.0 support for easy overclocking. Compatible with Intel and AMD platforms, this kit includes two 16GB modules. The black finish complements any high-performance build".

## Description elements

The elements a complete description carries:

| **Element** | **Why include** | **Example** |
|-------------|-----------------|-------------|
| **Brand + product name** | Identification, brand searches | "Nike Air Zoom Pegasus 40" |
| **Product type** | Category matching | "running shoes", "protein powder" |
| **Target audience** | Relevance signals | "athletes", "home cooks", "gamers" |
| **Key features** | Matching + conversion | "noise cancelling", "waterproof" |
| **Specifications** | Technical searches | "32GB", "5000 lumens", "100ml" |
| **Materials** | Quality signals | "premium leather", "organic cotton" |
| **Dimensions** | Size searches | "55x28 inches", "7 feet tall" |
| **Color** | Variant searches | "Space Gray", "Navy Blue" |
| **Use cases** | Intent matching | "perfect for gaming", "ideal for travel" |
| **Benefits** | Conversion | "all-day comfort", "fast results" |
| **What's included** | Purchase clarity | "includes charger and case" |

## Common description mistakes

| **Mistake** | **Example** | **Why it fails** | **Fix** |
|-------------|-------------|------------------|---------|
| Too short | "Great product". | No matching keywords | Add features, specs, benefits |
| Promotional text | "50% off today! Best deal ever!" | Causes disapproval | Remove promotional language |
| Links | "Visit example.com for more" | Not allowed in descriptions | Remove links |
| HTML markup | "<b>Great shoes</b>" | Not rendered, looks bad | Use plain text |
| Keyword stuffing | "shoes running shoes athletic shoes" | Spammy, may be disapproved | Use natural language |
| Generic | "High quality product you'll love" | No specific info | Add specific features |
| Wrong product | Describing accessories not the main product | Confusing, irrelevant matching | Describe only the product |
