## Purpose

This SOP walks you through building a high-converting landing page using the five-step Conversion Amplifier Framework, from offer definition through deployment.

> ❓ **The big question:** How do I systematically build a landing page that turns the right visitors into leads or trials?

This SOP covers Lead Gen and SaaS landing pages. For ecommerce product/category pages, see [SOP – Build a High-Converting Product Page](../sops/SOP – Build a High-Converting Product Page.md).

- Replacing a generic website page with a conversion-focused LP

## Decision gate: Awareness level

Before building, determine the primary traffic awareness level. This determines page length and section emphasis.

| If traffic is... | Then build... | Section emphasis |
|-----------------|--------------|-----------------|
| Most Aware (branded, retargeting) | Short-form page | Direct offer, light proof, strong CTA |
| Product Aware (competitor, comparison) | Medium page | Differentiators, heavy proof, moderate objections |
| Solution Aware (generic intent) | Full-length page | Benefits, heavy trust/proof, heavy objections |
| Problem Aware (pain keywords) | Long-form page | Problem agitation, education, heavy benefits, heavy trust |

## Phase 1️⃣: Define the offer

The offer drives everything. If the offer is not compelling, no amount of copy or design fixes the page.

### 1.1 Complete the Irresistible Offer brief

| Component | Your answer | Test question |
|-----------|-------------|---------------|
| **Clear Value Proposition** | | Can a stranger understand this in 5 seconds? |
| **Unique Selling Points** | | Why you and not the next option? |
| **Value Boosters** | | What extras make this feel like a steal? |
| **Social Proof** | | Why should I believe these claims? |
| **Risk Removal** | | What do I lose if this doesn't work? (Must answer: nothing) |

All five components must be defined before proceeding.

### 1.2 Define the primary conversion action

| Vertical | Common primary actions |
|----------|---------------------|
| Lead Gen | Form submission, phone call, consultation booking |
| SaaS | Free trial signup, demo request, account creation |

Record: Primary action = ___________

## Phase 2️⃣: Build the hierarchy

### 2.1 Select sections

Using the LP Hierarchy Blueprint, determine which sections to include based on awareness level:

| Section | Most Aware | Product Aware | Solution Aware | Problem Aware |
|---------|-----------|--------------|---------------|--------------|
| 1. Hero | Full | Full | Full | Full (problem-focused) |
| 2. Benefits | Light | Moderate | Heavy | Heavy (educational) |
| 3. Trust/Authority | Light | Moderate | Heavy | Heavy |
| 4. Social Proof | Light | Heavy | Heavy | Moderate |
| 5. Objection Handling | Minimal | Moderate | Heavy | Heavy |
| 6. Urgency/Scarcity | Strong | Moderate | Moderate | Light |
| 7. CTA | Repeated | Repeated | Repeated | Repeated |

### 2.2 Create page outline

List each section with:
- Section name
- Key message for this section
- Content type (text, table, video, testimonial, FAQ)
- Supporting catalog reference (for content patterns)

---

## Phase 3️⃣: Write the copy

### 3.1 Choose a copywriting framework

| Framework | Structure | Best for |
|-----------|-----------|----------|
| **AIDA** | Attention → Interest → Desire → Action | Long-form, cold traffic, complex solutions |
| **PAS** | Problem → Agitation → Solution | Pain-focused offers, emotional triggers |
| **BAB** | Before → After → Bridge | Transformation offers, coaching/consulting |
| **Hook-Story-Offer** | Hook → Story → Offer | Personal brands, narrative-driven pages |

Combine elements across frameworks. A PAS opening with an AIDA middle section is valid.

### 3.2 Write section by section

For each section, use the corresponding patterns from the catalogs:

1. **Hero:** Write headline using [LP Headline Catalog](../catalogs/LP Headline Catalog.md). Write sub-headline. Select visual approach.
2. **Benefits:** Translate features to benefits using FAB framework. Cover functional, business, and personal angles.
3. **Trust/Authority:** Select trust elements appropriate to vertical (institutional vs expertise).
4. **Social Proof:** Select proof types. Write or gather testimonials following the formula: specific result + before state + after state.
5. **Objection Handling:** Identify top 3-5 objections. Write FAQ or guarantee copy.
6. **Urgency/Scarcity:** Only include if legitimate. Write specific numbers and dates.
7. **CTA:** Write button text using [LP CTA Catalog](../catalogs/LP CTA Catalog.md). Write microcopy for each CTA placement.

### 3.3 Validate copy quality

Check against these principles:

- [ ] Visitor-first language (their reality, not your company)
- [ ] Outcomes over features throughout
- [ ] Specific numbers and results where possible
- [ ] Active voice, no hedging
- [ ] Message match with the ad that drives traffic

---

## Phase 4️⃣: Design

### 4.1 Apply design principles

| Principle | Application |
|-----------|------------|
| **Visual hierarchy** | Headline and CTA get the most visual weight |
| **White space** | Give elements room to breathe |
| **Contrast** | CTA buttons pop against background |
| **Consistency** | Colors, fonts, spacing follow a system |
| **Supportive visuals** | Images reinforce the message, never distract |
| **Mobile-first** | Design for mobile first, adapt for desktop |

### 4.2 Design review

- [ ] CTA buttons are the most visually prominent elements
- [ ] No competing visual focal points
- [ ] Sufficient white space between sections
- [ ] Images are real (product shots, team photos, results), not generic stock
- [ ] Mobile layout is fully functional with tap-friendly CTAs

---

## Phase 5️⃣: Build and launch

### 5.1 Implement

1. Build the page in your LP tool (Unbounce, Instapage, WordPress, etc.)
2. Implement the one-page-one-goal rule: remove navigation, footer links, social icons
3. Set up the form with minimum required fields
4. Add conversion tracking (Google Ads conversion pixel, GA4 events)
5. Set up thank-you page or confirmation state

### 5.2 Technical checks

- [ ] Page loads in under 3 seconds (test with PageSpeed Insights)
- [ ] Fully responsive on mobile (test on real devices)
- [ ] Form submits correctly and reaches CRM/email
- [ ] Conversion tracking fires on form submission (test with Tag Assistant)
- [ ] Thank-you page displays after conversion
- [ ] No broken links or missing images
- [ ] Legal links open in new tabs (privacy policy, terms)

### 5.3 Message match verification

- [ ] LP headline mirrors the ad headline language
- [ ] LP visuals match display/video ad visuals (if applicable)
- [ ] The offer on the LP matches the ad promise exactly
- [ ] For Search: headline contains the primary keyword

### 5.4 Final validation

Run the full [LP Quality Checklist](../checklists/LP Quality Checklist.md). All items must pass before launch.

### 5.5 Launch

1. Connect the LP URL to the campaign
2. Monitor for 24-48 hours: verify conversions are tracking correctly
3. Check that real form submissions are reaching the CRM

## Validation and definition of done

This SOP is complete when:

- [ ] All five Irresistible Offer components are defined and present on the page
- [ ] Page follows the LP Hierarchy (all applicable sections present and ordered)
- [ ] Copy uses benefit-first language with no hedging
- [ ] Design serves the copy with clear visual hierarchy
- [ ] Page loads in under 3 seconds on mobile
- [ ] Conversion tracking is verified and firing correctly
- [ ] Message match confirmed with the driving ad
- [ ] [LP Quality Checklist](../checklists/LP Quality Checklist.md) passed

## Exit → Entry bridge

Once the LP is live:

| Timeframe | Action |
|-----------|--------|
| First 48 hours | Monitor conversion tracking, verify form submissions |
| First 2 weeks | Gather baseline data (CVR, bounce rate, scroll depth) |
| After 50+ conversions | Evaluate performance against target CPA/ROAS |
| Ongoing | Run [SOP – Audit and Optimize an Existing Landing Page](../sops/SOP – Audit and Optimize an Existing Landing Page.md) for optimization |

**If conversion rate is below expectations:**

| Issue | Route to |
|-------|----------|
| High bounce rate (>70%) | Check message match, hero section clarity |
| Low scroll depth | Check benefits section, visual hierarchy |
| Scroll but no conversion | Check objection handling, CTA copy, form friction |

## Common failures

| Failure | Why it happens | How to avoid |
|---------|----------------|--------------|
| Skipping the offer definition | Rushing straight to copy/design | Phase 1 is non-negotiable: always start with the offer |
| Writing copy before defining hierarchy | Leads to unfocused, rambling pages | Complete Phase 2 outline before writing a single word |
| Generic stock photos | Doesn't reinforce the message or build trust | Use real product shots, team photos, or customer results |
| Multiple competing CTAs | Splits visitor attention, reduces conversions | One primary CTA per page, repeated throughout |
| No message match | Visitor thinks they landed on the wrong page | Mirror ad language in LP headline |
| Too many form fields | Each extra field reduces conversion rate | Ask only what is needed to qualify and follow up |
