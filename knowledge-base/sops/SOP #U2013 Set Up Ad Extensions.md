# SOP – Set Up Ad Extensions
Created: 2026-04-02

SOP_ID: SOP_90
Status: Done
Category: Creative
Primary Outcome: All applicable extension types configured at the correct level with complete, relevant content
Agent_Executable: No
Human_Approval_Required: No
Domain: Creative
Pillar: 8

## Purpose

Sets up all applicable ad extension types for a new campaign or account. Covers sitelinks, callouts, structured snippets, images, promotions, prices, call, location, lead form, and automated asset controls.

> ❓ **The big question:** Does every campaign have the right extensions configured at the right level to maximize ad real estate and CTR?

---

## What this SOP is NOT

This SOP does **not:**

- Optimize or replace existing extensions (See: [SOP – Review and Optimize Ad Extensions](../sops/SOP – Review and Optimize Ad Extensions.md))
- Define extension specifications or character limits (See: [Extension Leverage Catalog](../catalogs/Extension Leverage Catalog.md))
- Set automated asset policies (See: [Automated Assets Control Guidelines](../guidelines/Automated Assets Control Guidelines.md))
- Compose RSA headlines and descriptions (See: [SOP – Write Compelling RSAs](../sops/SOP – Write Compelling RSAs.md))

## When to run this SOP

- Setting up a new Google Ads account
- Launching a new campaign that needs extension coverage
- After an extension coverage audit reveals missing types (See: [Extension Coverage Checklist](../checklists/Extension Coverage Checklist.md))

## Phase 1️⃣: Core extensions (account level)

Set these at account level so all campaigns inherit them by default.

### 1.1 Sitelinks

Create 4-8 sitelinks pointing to your most important pages:

| Sitelink slot | What to link | Example |
|--------------|-------------|---------|
| 1 | Primary conversion page | "Pricing", "Free Trial", "Request Quote" |
| 2 | Key product/service page | "Features", "Solutions", "Product Range" |
| 3 | Trust/credibility page | "Case Studies", "Reviews", "About Us" |
| 4 | Support/resource page | "Help Center", "Blog", "Contact" |
| 5-8 | Additional pages (category, seasonal, secondary offers) | As applicable |

For each sitelink: add 2 description lines (35 characters each). Sitelinks without descriptions are less likely to show.

### 1.2 Callouts

Create 4-8 callouts highlighting benefits and differentiators:

| Callout type | Examples |
|-------------|---------|
| Delivery/speed | "Free Shipping", "Same-Day Delivery", "Setup in 2 Minutes" |
| Trust signals | "4.8★ on Google", "Certified Partner", "10,000+ Customers" |
| Risk removal | "30-Day Money Back", "No Contract", "Free Returns" |
| Differentiators | "24/7 Support", "Made in [Country]", "Family-Owned Since 2005" |

### 1.3 Structured snippets

Create 2-4 structured snippet headers relevant to your business:

| Header type | When to use | Example values |
|-------------|-------------|---------------|
| Types | Multiple service/product categories | "SEO, PPC, Social Media, Email Marketing" |
| Brands | Retailer with brand portfolio | "Nike, Adidas, Puma, New Balance" |
| Destinations | Travel/hospitality | "Amsterdam, London, Paris, Barcelona" |
| Courses | Education/training | "Beginner, Advanced, Masterclass" |

### 1.4 Image extensions

Upload 1-4 images per campaign:

| Format | Size | Requirement |
|--------|------|-------------|
| Square | 1200×1200 | Required (minimum 1) |
| Landscape | 1200×628 | Recommended |

Use product images, lifestyle shots, or branded visuals. No text overlays, no logos as the primary image.

### 1.5 Business name and logo

| Asset | Requirement |
|-------|-------------|
| Business name | Enter your legal business name |
| Logo | Upload square logo (1200×1200 minimum) |

**Verification:** Preview all account-level extensions in the Extensions section. Confirm 4+ sitelinks, 4+ callouts, 2+ structured snippet headers, 1+ image, business name, and logo are active.

## Phase 2️⃣: Campaign-specific extensions

Add these at campaign level for campaigns where they apply.

### 2.1 Promotion extensions

Add when you have active promotions:

| Field | What to enter |
|-------|-------------|
| Occasion | Select from dropdown (if seasonal) or "None" |
| Promotion type | Monetary discount, percent discount, or "up to" discount |
| Item | What is discounted |
| Final URL | Landing page for the promotion |
| Dates | Start and end dates (set end date to auto-remove) |

> 💡 **Set end dates on all promotion extensions.** Expired promotions that remain active erode trust and waste clicks.

### 2.2 Price extensions

Add when you have fixed pricing for products or services:

| Field | What to enter |
|-------|-------------|
| Type | Brands, Events, Locations, Neighborhoods, Product Categories, Product Tiers, Service Categories, Service Tiers, Services |
| Items | 3-8 price items with name, price, description, and URL |

Price extensions work well for: SaaS pricing tiers, service packages, ecommerce category starting prices.

### 2.3 Call extensions

Add for campaigns where phone calls are a conversion action:

| Setting | Recommendation |
|---------|---------------|
| Phone number | Local or toll-free number |
| Call reporting | Enable (track calls as conversions) |
| Schedule | Match business hours only |

> ⚠️ **Do not add call extensions to campaigns where phone calls are not a goal.** Calls from non-phone campaigns inflate CPC without generating desired conversions.

**Verification:** Review campaign-level extensions. Confirm promotion/price/call extensions appear on the correct campaigns only.

## Phase 3️⃣: Situational extensions

### 3.1 Location extensions

Add only if you have a physical location customers visit:

| Prerequisite | Action |
|-------------|--------|
| Google Business Profile linked | Link in Google Ads > Ads & assets > Assets > Location |
| Multiple locations | Link all relevant locations, use campaign-level filtering |
| No physical location | Skip this extension entirely |

### 3.2 Lead form extensions

Add for Lead Gen campaigns where in-ad form submission is desired:

| Consideration | Guidance |
|--------------|---------|
| Lead quality | Lead form leads are typically lower quality than landing page leads. Set expectations accordingly. |
| Form fields | Use 3-5 fields maximum. More fields = fewer submissions but higher quality. |
| CRM integration | Connect to your CRM via webhook or Zapier for immediate follow-up. |
| Organic message | Add a compelling reason to fill out the form (offer, download, consultation). |

> ⚠️ **Lead form extensions can cannibalize landing page conversions.** Monitor whether total conversion volume increases or simply shifts from landing page to form. If total volume stays flat, the form is cannibalizing, not adding incremental leads.

### 3.3 App extensions

Add only if you have a mobile app and want to drive installs from Search ads:

| When to add | When to skip |
|------------|-------------|
| App installs are a business goal | App exists but installs are not a priority |
| Mobile traffic is significant | Desktop-heavy campaigns |

**Verification:** Situational extensions configured only where applicable. No location extensions on online-only businesses, no call extensions outside business hours.

## Phase 4️⃣: Automated asset controls

Navigate to Ads & assets > Assets > Automated assets (account level).

| Auto-generated asset | Recommendation | Rationale |
|---------------------|---------------|-----------|
| Dynamic sitelinks | Enable | Supplements your manual sitelinks with relevant page links |
| Dynamic callouts | Enable | Adds benefit highlights from your landing pages |
| Dynamic structured snippets | Enable | Pulls category information from your site |
| Seller ratings | Enable (if eligible) | Shows star ratings from third-party review sites |
| Dynamic image extensions | Disable | Images from your site are often low-quality or irrelevant |
| Longer ad headlines | Enable with monitoring | Google generates longer headlines from landing page content |
| Automated business name/logo | Disable if manual versions are set | Prefer your controlled versions |

> ↪️ **Full automated asset policy.** See [Automated Assets Control Guidelines](../guidelines/Automated Assets Control Guidelines.md) for detailed enable/disable rationale and exception conditions.

**Verification:** Automated asset settings match the recommendations above. Dynamic image extensions disabled.

## Phase 5️⃣: Validation

Run the [Extension Coverage Checklist](../checklists/Extension Coverage Checklist.md) against all campaigns:

- [ ] 4+ sitelinks with descriptions at account level
- [ ] 4+ callouts at account level
- [ ] 2+ structured snippet headers at account level
- [ ] 1+ image extension (square minimum) at account level
- [ ] Business name and logo configured
- [ ] Promotion extensions on campaigns with active offers (with end dates)
- [ ] Price extensions on campaigns with fixed pricing
- [ ] Call extensions on phone-conversion campaigns only (with schedule)
- [ ] Location extensions on campaigns for physical businesses only
- [ ] Lead form extensions on lead gen campaigns (with CRM integration)
- [ ] Automated asset settings reviewed and configured

---

## Validation and definition of done

This SOP is complete when:

- [ ] All core extensions (sitelinks, callouts, snippets, images, name/logo) are active at account level
- [ ] Campaign-specific extensions are applied to the correct campaigns only
- [ ] Situational extensions are configured where applicable
- [ ] Automated asset controls are set per guidelines
- [ ] Extension Coverage Checklist passes for all campaigns
- [ ] No extension type is active on a campaign where it does not belong

## Common failures

| Failure | How to avoid |
|---------|--------------|
| No sitelink descriptions | Fill both description lines for every sitelink |
| Call extensions on non-phone campaigns | Only add call extensions where phone calls are a conversion goal |
| Expired promotion extensions running | Set end dates on all promotions |
| Lead form cannibalizing LP conversions | Monitor total conversion volume, not just form submissions |
| Missing image extensions | Upload at least one square image at account level |
| Automated dynamic images enabled | Disable: auto-pulled images are often low-quality |
