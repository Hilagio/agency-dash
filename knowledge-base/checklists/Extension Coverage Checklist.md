## Purpose

Validates that extension coverage is complete, properly configured, and adds distinct value beyond RSA copy.

---

## What this checklist validates

This checklist confirms:

- Presence of required core extensions
- Minimum quantities met per extension type
- Quality requirements per extension type
- Situational extension fit evaluated
- No duplicate messaging across assets

This checklist does **NOT**:

- List extension content options (See: [Extension Leverage Catalog](../catalogs/Extension Leverage Catalog.md))
- Prescribe automated asset settings (See: [Automated Assets Control Guidelines](../guidelines/Automated Assets Control Guidelines.md))
- Provide step-by-step execution instructions

---

## When to use

Run this checklist:

- After completing extension setup for new campaigns
- When auditing existing campaigns for coverage gaps
- Before launching Performance Max campaigns

---

## Checklist

### Core extensions

- [ ]  Sitelinks: 4-8 active, covering different user intents
- [ ]  Sitelinks: Descriptions added, URLs functional, no RSA headline duplication
- [ ]  Callouts: 4-8 active, each highlighting a distinct benefit
- [ ]  Callouts: Mix of categories (trust, value, speed, features, risk)
- [ ]  Structured Snippets: 2+ headers active with 4+ specific values each
- [ ]  Image Extensions: 3-5 high-resolution images (1200×1200 min), no excessive text
- [ ]  Business Name: Set, approved, matches legal/brand name
- [ ]  Business Logo: High-res square (1200×1200), legible at small sizes

### Situational extensions

- [ ]  Promotion: Evaluated; if active sale exists → extension created with dates configured
- [ ]  Price: Evaluated; if pricing is competitive → 3-8 items with accurate pricing
- [ ]  Call: Evaluated; if phone leads valuable → extension with scheduling and reporting
- [ ]  Location: Evaluated; if physical locations matter → GBP linked and verified
- [ ]  Lead Form: Evaluated; if lead gen primary and volume trade-off acceptable → testing
- [ ]  Message: Evaluated; if conversational sales fits → asset created, no platform in headlines
- [ ]  App: Evaluated; if downloads strategic and won't cannibalize web → asset created

### Non-duplication

- [ ]  Sitelinks don't repeat RSA headlines
- [ ]  Callouts don't repeat RSA headlines or sitelink text
- [ ]  Promotion content not duplicated in callouts

### Technical status

- [ ]  All extensions show "Approved" status
- [ ]  No "Limited" or "Disapproved" without investigation
- [ ]  Promotion extensions have correct date ranges
