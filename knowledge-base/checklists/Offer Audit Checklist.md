## Purpose

This checklist validates whether an offer has the foundational elements required to be "irresistible", meaning your ideal customer **would feel stupid saying no**.

---

## What this validates / What this does NOT validate

**This checklist validates:**

- Presence of core offer elements (Value, Uniqueness, Urgency, Trust)
- Strength of each element relative to market expectations
- Overall offer readiness for advertising

**This checklist does NOT validate:**

- How well the offer is communicated in ads
    - See: [Offer Angle Quality Checklist](../checklists/Offer Angle Quality Checklist.md)
- Headline or description quality
    - See: [Headline Quality Checklist](../checklists/Headline Quality Checklist.md), [Description Quality Checklist](../checklists/Description Quality Checklist.md)
- Landing page experience
    - See: [SOP – Improve Landing Page Experience](../sops/SOP – Improve Landing Page Experience.md)

## The 4 Pillars of an Irresistible Offer

| Pillar | Question it answers | What to check |
| --- | --- | --- |
| **Value** | "Is this worth it?" | Problem solved, outcome clarity, perceived value |
| **Uniqueness** | "Why you over others?" | Differentiation, comparison resistance |
| **Urgency** | "Why now?" | Reason to act immediately |
| **Trust** | "What if it doesn't work?" | Risk removal, proof, credibility |

---

## Offer Audit Checklist

### Value

- [ ]  The offer solves a real, painful problem
- [ ]  The dream outcome is clear and specific
- [ ]  The ideal customer wants this, not only needs it
- [ ]  Perceived value exceeds the price and effort required

### Uniqueness

- [ ]  The offer cannot be directly compared to a competitor's
- [ ]  The offer includes at least one claim only this business can make
- [ ]  Enough value is stacked that price comparison is impractical
- [ ]  The offer addresses a specific audience, not everyone

### Urgency

- [ ]  A reason to act now rather than later is stated
- [ ]  The urgency is real, not manufactured scarcity
- [ ]  The deadline or limit is stated on the page

### Trust

- [ ]  The customer's risk is named and removed
- [ ]  A guarantee, trial or refund policy is in place
- [ ]  Proof it works is present: testimonials, reviews or case studies
- [ ]  Credibility signals are present: awards, certifications or user counts

## Gap Identification

If you can't check a box, use this table to diagnose and fix:

| Missing Element | What It Signals | Action |
| --- | --- | --- |
| **No clear problem solved** | Don't understand customer pain | Customer interviews, review mining |
| **Unclear dream outcome** | Feature-focused, not outcome-focused | Reframe around transformation |
| **Low perceived value** | Price/effort too high relative to outcome | Stack value, reduce friction, reframe |
| **Easily compared to competitors** | Commoditized offer | Add unique mechanism, specialize, bundle |
| **Nothing unique to claim** | No differentiation | Find or create proprietary element |
| **No urgency** | No reason to act now | Add authentic scarcity or deadline |
| **Fake urgency** | Urgency that isn't real | Replace with authentic constraint |
| **No risk removal** | Asking too much commitment | Add guarantee, trial, or refund policy |
| **No social proof** | Haven't collected it | Start collecting reviews immediately |
| **No credibility signals** | Haven't built authority | Pursue certifications, awards, partnerships |

## Vertical-Specific Minimum Requirements

### Lead Gen

| Element | Minimum requirement |
| --- | --- |
| Value | Specific deliverable with perceived monetary value |
| Uniqueness | Specialization or proprietary method |
| Urgency | Capacity limit or time-bound offer |
| Trust | "No obligation" + testimonials/case studies |

### SaaS

| Element | Minimum requirement |
| --- | --- |
| Value | Clear time-to-value ("results in X minutes") |
| Uniqueness | Feature or approach competitors can't match |
| Urgency | Pricing lock-in or limited beta access |
| Trust | Free trial (no credit card) + money-back guarantee |

### Ecommerce

| Element | Minimum requirement |
| --- | --- |
| Value | Bundle or threshold incentive |
| Uniqueness | Product differentiation or exclusive offer structure |
| Urgency | Sale deadline or stock scarcity (real) |
| Trust | Extended return window + ratings/reviews |
