## Purpose

Validates that a landing page (Lead Gen/SaaS) meets all conversion requirements before launch or after optimization.

---

## What this checklist validates

This checklist confirms:

- All 7 LP hierarchy sections are present and properly sequenced
- Hero section meets the 5-second clarity test
- Copy follows benefit-first principles
- Technical requirements for conversion are met
- Message match with traffic source is confirmed

This checklist does **NOT:**

- Validate ecommerce product pages (See: [Ecommerce Conversion Engine Mental Model](../mental-models/Ecommerce Conversion Engine Mental Model.md))
- Provide patterns or examples for sections (See: [LP Section Catalog](../catalogs/LP Section Catalog.md))
- Evaluate A/B test design (See: [Testing and Experimentation Mental Model](../mental-models/Testing and Experimentation Mental Model.md))
- Execute the build process (See: [SOP – Build a High-Converting Landing Page](../sops/SOP – Build a High-Converting Landing Page.md))

---

## When to use

Run this checklist:

- After completing the Build phase of the Conversion Amplifier Framework
- Before launching a new landing page
- When auditing an existing landing page for conversion issues
- After making significant changes to an existing page

## Checklist

### Offer

- [ ] Core value proposition is defined in one sentence
- [ ] Unique selling points are identified and explicitly stated on the page
- [ ] Value boosters are present (bonuses, extras, bundles)
- [ ] Social proof is present on the page
- [ ] Risk removal element exists (guarantee, free trial, return policy)
- [ ] All five Irresistible Offer components are present (value prop, USPs, value boosters, social proof, risk removal)

### Hero section

- [ ] Primary headline is under 10 words
- [ ] Headline communicates the core outcome, not a feature
- [ ] Sub-headline adds specificity without repeating the headline
- [ ] The value proposition is clear without industry knowledge within 5 seconds
- [ ] Visual element reinforces the message (not generic stock)
- [ ] Primary CTA is visible above the fold
- [ ] CTA button text is benefit-driven and first-person
- [ ] CTA button has contrasting color against the background

### Benefits section

- [ ] Benefits focus on outcomes, not features
- [ ] At least two of three angles covered (functional, business, personal)
- [ ] "So what?" test passed: each benefit answers why the visitor should care
- [ ] No jargon: a non-expert can understand every benefit

### Trust/Authority section

- [ ] At least one trust element is present (certifications, credentials, awards, media mentions)
- [ ] Trust claims are specific and verifiable (not "We can be trusted")
- [ ] Trust type matches the vertical (institutional for regulated, expertise for services)
- [ ] Trust section appears before social proof section

### Social proof section

- [ ] At least one form of social proof is present
- [ ] Testimonials include full name, photo, and company (not anonymous)
- [ ] Testimonials are specific with results, not generic ("Great service!")
- [ ] Social proof matches the target visitor segment
- [ ] Third-party validation included if available (G2, Trustpilot, industry ratings)

### Objection handling

- [ ] Top 3 visitor objections are identified and addressed
- [ ] FAQ section covers pricing, implementation, timing, and trust concerns
- [ ] Guarantee is specific (duration, process, conditions)
- [ ] Guarantee is placed near a conversion point

### Urgency/Scarcity (if used)

- [ ] Urgency or scarcity is legitimate (not fake)
- [ ] Specific numbers and dates are used (not "limited time" or "act now")
- [ ] Reason for limitation is explained
- [ ] Urgency appears after value and trust are established

### Call to action

- [ ] Primary CTA is repeated at least 3 times throughout the page
- [ ] CTA placement follows the hierarchy: after hero, after proof, after objections, final section
- [ ] CTA button text is consistent across placements (same action, same language)
- [ ] Microcopy near CTA reinforces the decision (risk removal, social proof, or urgency)
- [ ] Secondary CTA (if used) is clearly subordinate to primary and advances the same goal

### Copy quality

- [ ] Active voice throughout ("Get your assessment" not "An assessment can be requested")
- [ ] No hedging language ("Do X" not "You might want to consider X")
- [ ] Visitor-first language (focuses on their reality, not your company)
- [ ] Claims use specific numbers and results, not "great results"
- [ ] No jargon or corporate speak

### One-page-one-goal rule

- [ ] Navigation bar is removed or minimized
- [ ] Footer links are removed (except legal requirements)
- [ ] Social media icons are removed from the page
- [ ] No competing offers or CTAs that lead away from the primary goal
- [ ] Every element on the page either drives conversion or is removed

### Message match

- [ ] LP headline reflects the ad copy that drives traffic to this page
- [ ] LP visuals match display/video ad visuals (if applicable)
- [ ] The offer on the LP matches what the ad promises (no bait-and-switch)
- [ ] For Search traffic: headline contains the primary keyword or close variant

### Technical requirements

- [ ] Page loads in under 3 seconds
- [ ] Page is fully responsive on mobile (no horizontal scroll, tap-friendly CTAs)
- [ ] Form contains only the fields required to complete the conversion
- [ ] Conversion tracking fires correctly on form submission or purchase
- [ ] Thank you page or confirmation state exists after conversion
