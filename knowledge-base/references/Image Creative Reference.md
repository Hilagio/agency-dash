## Quick reference: Image specifications

### Display campaigns

| Aspect Ratio | Dimensions (px) | Priority | Use case |
| --- | --- | --- | --- |
| Landscape (1.91:1) | 1200 × 628 | Required | Standard display placements |
| Square (1:1) | 1200 × 1200 | Required | Native, social-style placements |
| Portrait (9:16) | 900 x 1600 | Recommended | Mobile-first placements |

### Demand Gen campaigns

| Aspect Ratio | Dimensions (px) | Priority | Use case |
| --- | --- | --- | --- |
| Landscape (1.91:1) | 1200 × 628 | Required | YouTube, Discover, Gmail |
| Square (1:1) | 1200 × 1200 | Required | Feed placements |
| Portrait (4:5) | 960 × 1200 | Recommended | YouTube Shorts, mobile |
| Vertical (9:16) | 1080 × 1920 | Recommended | YouTube Shorts |

### Performance Max campaigns

| Aspect Ratio | Dimensions (px) | Priority | Use case |
| --- | --- | --- | --- |
| Landscape (1.91:1) | 1200 × 628 | Required | Search, Display, Discover |
| Square (1:1) | 1200 × 1200 | Required | All placements |
| Portrait (4:5) | 960 × 1200 | Strongly recommended | Mobile, YouTube |
| Vertical (9:16) | 1080 × 1920 | Recommended | YouTube Shorts |

## Recommended image quantity

| Campaign Type | Minimum | Recommended | Maximum |
| --- | --- | --- | --- |
| Display | 1 per ratio | 3-5 per ratio | 15 total |
| Demand Gen | 3 total | 5-10 total | 20 total |
| Performance Max | 3 total | 10-15 total | 20 total |

> 💡 **Why more images?** More variations = more testing = better optimization. Google tests combinations across placements.

## Logo specifications

### Square logo (1:1)

| Specification | Requirement |
| --- | --- |
| Dimensions | 1200 × 1200 px (recommended) |
| Minimum | 128 × 128 px |
| Background | Transparent or solid (white/brand color) |
| Content | Logo mark only, no taglines |

### Landscape logo (4:1)

| Specification | Requirement |
| --- | --- |
| Dimensions | 1200 × 300 px (recommended) |
| Minimum | 512 × 128 px |
| Background | Transparent or solid |
| Content | Logo with wordmark acceptable |

### Logo best practices

| Do | Don't |
| --- | --- |
| Use official brand logo | Use outdated logo versions |
| Ensure legibility at small sizes | Add decorative elements |
| Use transparent background when possible | Use complex backgrounds |
| Test at 50×50 px for visibility | Assume large display size |
| Include padding/clear space | Crop logo to edges |

## Image composition guidelines

### The rule of thirds

Divide image into 9 equal parts with 2 horizontal and 2 vertical lines. Place key elements along these lines or at their intersections.

```
┌─────┬─────┬─────┐
│     │     │     │
├─────┼─────┼─────┤
│     │ KEY │     │
├─────┼─────┼─────┤
│     │     │     │
└─────┴─────┴─────┘
```

### Safe zones

| Zone | Guidance |
| --- | --- |
| Center 80% | Safe for critical content (product, faces, text) |
| Outer 10% | May be cropped on some placements |
| Corners | Avoid critical elements (overlay buttons may appear) |

### Composition principles

| Principle | Implementation |
| --- | --- |
| Single focal point | One clear subject, not competing elements |
| High contrast | Subject stands out from background |
| Minimal text | Let image do the work (text in headlines instead) |
| Clean backgrounds | Simple > busy; solid colors or subtle patterns |
| Real photography | Authentic images outperform stock |
| People when relevant | Faces drive engagement (when appropriate) |

## Text on images

### Google's text policy

Google recommends **minimal or no text** on images. Text-heavy images:

- May be disapproved
- Often perform worse (cluttered, hard to read)
- Compete with ad copy for attention

### When text is acceptable

| Acceptable | Not Recommended |
| --- | --- |
| Brand name/logo | Repeating headline text |
| Short call-to-action | Paragraphs of copy |
| Price/discount (if key message) | Terms and conditions |
| Product name | Contact information |

### Text guidelines (if used)

| Guideline | Implementation |
| --- | --- |
| Coverage | Max 20% of image area |
| Legibility | Large, high-contrast, readable at small sizes |
| Placement | Don't obscure key visual elements |
| Redundancy | Don't duplicate headline/description text |

## Image quality standards

### Technical quality

| Standard | Requirement |
| --- | --- |
| Resolution | Sharp, not pixelated or blurry |
| Lighting | Well-lit, not underexposed or overexposed |
| Focus | Subject in sharp focus |
| Color | Accurate, not oversaturated or washed out |
| Compression | Minimal artifacts from compression |

### Creative quality

| Standard | Implementation |
| --- | --- |
| Relevance | Image matches product/service and audience |
| Brand consistency | Aligns with brand visual identity |
| Emotional appeal | Evokes appropriate feeling for objective |
| Differentiation | Stands out from competitor imagery |
| Authenticity | Real/believable, not overly stock |

## Prohibited content

### Google Ads policy violations

| Prohibited | Examples |
| --- | --- |
| Misleading content | Fake buttons, fake notifications, deceptive claims |
| Shocking content | Violence, gore, disturbing imagery |
| Adult content | Sexual imagery, nudity |
| Dangerous products | Weapons, drugs, tobacco |
| Counterfeit goods | Fake brand products |
| Discriminatory content | Content targeting protected groups |

### Common disapproval triggers

| Trigger | How to Avoid |
| --- | --- |
| Simulated buttons | Don't add fake "Play", "Download", or "Click" buttons |
| Before/after claims | Avoid unrealistic transformation imagery |
| Excessive text | Keep text under 20% of image |
| Low quality | Use high-resolution, professional images |
| Misleading content | Ensure image accurately represents offering |

## Image types by purpose

### Product-focused images

| Use Case | Best Practices |
| --- | --- |
| Ecommerce | Clean product shots, white/simple backgrounds |
| Hero shots | Product as main subject, lifestyle context optional |
| Detail shots | Close-ups of key features, quality indicators |
| Scale reference | Product in context showing size/use |

### Lifestyle images

| Use Case | Best Practices |
| --- | --- |
| People using product | Authentic scenarios, relatable subjects |
| Aspirational | Desired outcome/lifestyle with product |
| Problem/solution | Before state or solved state visualization |
| Emotional | Faces showing relevant emotion |

### Brand images

| Use Case | Best Practices |
| --- | --- |
| Brand awareness | Strong brand colors, logo prominent |
| Campaign imagery | Consistent visual language across ads |
| Seasonal | Timely imagery (holidays, events) |

## Common mistakes

| Mistake | Problem | Fix |
| --- | --- | --- |
| Only one aspect ratio | Missing placements, limited reach | Create all required ratios |
| Low resolution | Pixelated on large displays | Use 1200 px minimum |
| Text-heavy images | Policy risk, poor performance | Minimize text, use ad copy instead |
| Busy backgrounds | Distracting, unclear message | Use clean, simple backgrounds |
| No clear focal point | Confusing, forgettable | Single subject, clear hierarchy |
| Generic stock photos | Inauthentic, low engagement | Use real/custom photography |
| Logo too small | Not visible at small sizes | Test at 50×50 px |
| Critical content at edges | Cropped on some placements | Keep key elements in center 80% |
| Inconsistent branding | Confusing, unprofessional | Maintain visual consistency |
| Image enhancements enabled | Quality degradation | Disable — create all sizes yourself |
