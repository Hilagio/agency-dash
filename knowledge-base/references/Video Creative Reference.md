## Quick reference: Video formats

| Format | Max duration | Skippable | Best for | Compatible campaigns |
| --- | --- | --- | --- | --- |
| Skippable In-Stream | No limit (< 3 min recommended) | After 5s | Engagement measurement, direct response | Demand Gen, Video View, Video Reach, PMax |
| In-Feed Video | No limit | N/A (user clicks) | Discovery, high-intent viewers | Demand Gen, Video View, Video Reach, PMax |
| YouTube Shorts | < 60 seconds recommended | Swipe | Mobile-first, engaged viewers | Demand Gen, Video View, Video Reach, PMax |
| Non-Skippable In-Stream | 15-60 seconds | No | Full message delivery, awareness | Video Reach |
| Bumper Ads | 6 seconds | No | Quick awareness, message reinforcement | Video Reach |

## The ABCD framework

| Principle | Question It Answers | Focus |
| --- | --- | --- |
| **A — Attention** | Will they keep watching? | Hook and sustain with immersive story |
| **B — Branding** | Will they remember who this is from? | Brand early, often, and richly |
| **C — Connection** | Will they care? | Help people think or feel something |
| **D — Direction** | Will they act? | Clear, specific call-to-action |

---

## A — Attention

> 💡 **Goal:** Hook viewers in the first 5 seconds and sustain attention throughout.

### Tactics

| Tactic | Implementation |
| --- | --- |
| Jump in | Get to the heart of the story immediately (no slow builds) |
| Support with audio | Reinforce message with voice-over and sound |
| Use supers | Add text overlays to reinforce key points |
| Keep visuals bright | High contrast, good lighting (optimized for mobile) |

### Hook types (first 5 seconds)

| Type | Example |
| --- | --- |
| Start in action | Open mid-scene, no setup |
| Bold statement | Provocative claim or question |
| Visual surprise | Unexpected imagery |
| Direct address | Speak directly to viewer |
| Problem statement | Name the pain immediately |

---

## B — Branding

> 💡 **Goal:** Ensure viewers know who the ad is from, even if they skip.

### Tactics

| Tactic | Implementation |
| --- | --- |
| Show up early | Brand visible in first 5 seconds |
| Maintain presence | Brand elements throughout, not just end card |
| Reinforce with audio | "See and say" (mention brand name aloud) |
| Use all brand assets | Logo, colors, product, packaging, tagline, jingle, mascot |

### Branding elements

| Element | Placement Options |
| --- | --- |
| Logo | Watermark, end card, product placement |
| Product | Hero shots, demonstrations, in-use |
| Colors | Backgrounds, graphics, clothing |
| Tagline | Text overlay, voice-over, end card |
| Jingle/Audio | Distinctive sound, brand music |
| Packaging | Product shots, unboxing |

> ⚠️ **Critical rule:** Skippers at 5 seconds should still know who the ad is from.

---

## C — Connection

> 💡 **Goal:** Make viewers think or feel something (emotion drives action).

### Tactics

| Tactic | Implementation |
| --- | --- |
| Humanize the story | Real people, relatable situations |
| Represent actual consumer | Target audience sees themselves |
| Focus the message | One clear message, simple language |
| Engage emotionally | Use emotional levers strategically |

### Emotional levers

| Lever | Effect |
| --- | --- |
| Humor | Makes them laugh, increases memorability |
| Surprise | Subverts expectations, holds attention |
| Intrigue | Creates curiosity, drives completion |
| Empathy | Shows recognized problem, builds trust |
| Aspiration | Shows better life, motivates action |
| Joy | Positive, uplifting associations |
| FOMO | Fear of missing out, drives urgency |

> ⚠️ **Key principle:** Show human benefit, not just product features.

---

## D — Direction

> 💡 **Goal:** Tell viewers exactly what to do next.

### Tactics

| Tactic | Implementation |
| --- | --- |
| Include a CTA | Be intentional about the specific objective |
| Supercharge with audio | Reinforce on-screen CTA with voice-over |
| Make it easy | Simple, clear instructions (one action only) |

### CTAs by objective

| Objective | CTA Examples |
| --- | --- |
| Awareness | "Learn more at [brand].com" |
| Consideration | "See how it works" / "Watch the demo" |
| Action | "Shop now" / "Get 20% off today" / "Download the app" |
| Lead Gen | "Book your free consultation" / "Get your quote" |

> ⚠️ **Critical rule:** One primary action only. Multiple CTAs create confusion.

## ABCD by marketing objective

### Awareness ads

| Principle | Emphasis |
| --- | --- |
| Attention | Pump up audio volume (demand attention) |
| Branding | Put brand front and center (multiple elements) |
| Connection | Make people core to story (be different yet simple) |
| Direction | Softer CTA acceptable |

### Consideration ads

| Principle | Emphasis |
| --- | --- |
| Attention | Apply core attention principles |
| Branding | Hero the product (tight beauty shots, demos) |
| Connection | Show how it works (be relatable) |
| Direction | Plant seed of urgency (e.g. "Learn more today") |

### Action/Conversion ads

| Principle | Emphasis |
| --- | --- |
| Attention | Apply core attention principles |
| Branding | Make product the ad (product is hero) |
| Connection | Be exact and tangible (specific benefits) |
| Direction | Present ask after context (strong CTA with incentive) |

### Full-funnel ads

| Principle | Emphasis |
| --- | --- |
| Attention | Hook with audio (focus on elements that deliver message) |
| Branding | Start with mix of elements, finish with product |
| Connection | Establish connection to support product story |
| Direction | Use CTAs throughout (become more direct as ad progresses) |

## Technical specifications

### Aspect ratios

| Ratio | Dimensions | Use case |
| --- | --- | --- |
| Horizontal (16:9) | 1920 x 1080 px (1080p) | Standard YouTube, desktop |
| Vertical (9:16) | 1080 x 1920 px (1080p) | YouTube Shorts, mobile-first |
| Square (1:1) | 1080 x 1080 px | Cross-platform, in-feed |

> ⚠️ **Performance note:** According to Google, campaigns with vertical videos see **10-20% more conversions**.

---

### Recommended approach

| Priority | Action |
| --- | --- |
| Best | Create all 3 ratios (maximize reach across placements/devices) |
| Good | Horizontal + vertical (cover most inventory) |
| Minimum | Horizontal only (limits mobile performance) |

---

### Duration guidelines

| Format | Minimum | Recommended | Maximum |
| --- | --- | --- | --- |
| Skippable In-Stream | 12 seconds | 15-60 seconds | No limit (< 3 min) |
| Non-Skippable In-Stream | 15 seconds | 15-30 seconds | 60 seconds |
| Bumper | — | 6 seconds | 6 seconds |
| YouTube Shorts | — | 15-30 seconds | 60 seconds |
| In-Feed | — | 30-90 seconds | No limit |

---

### Vertical video safe zones

| Zone | Coverage | Guideline |
| --- | --- | --- |
| Top | ~10% | May be covered by UI elements |
| Bottom | ~20% | May be covered by CTAs, buttons, text |
| Center | ~70% | Safe zone — keep critical content here |

> ⚠️ **Critical content to keep in center 70%:** Logo, product, text, faces, key visual details.

## Format selection guide

### Step 1️⃣: Check format availability

Your campaign type determines which formats are available:

| Format | Video Reach | Video Views | Demand Gen | PMax |
| --- | --- | --- | --- | --- |
| Skippable In-Stream | ✅ | ✅ | ✅ | ✅ * |
| Non-Skippable In-Stream | ✅ | ❌ | ❌ | ❌ |
| Bumper (6s) | ✅ | ❌ | ❌ | ❌ |
| In-Feed Video | ✅ | ✅ | ✅ | ✅ * |
| YouTube Shorts | ✅ | ✅ | ✅ | ✅ * |

> 💡 **Non-Skippable and Bumper ads are Video Reach exclusives:** If you need guaranteed full-message delivery, you must use a Video Reach campaign.

### Step 2️⃣: Select format by campaign type and objective

**Video Reach campaigns** (all formats available):

```jsx
What's your primary objective?
│
├─ Guaranteed full message delivery?
│  └─ YES → Non-Skippable In-Stream (15-30s)
│
├─ Maximum reach at lowest CPM?
│  └─ YES → Bumper Ads (6s) or Non-Skippable mix
│
├─ Mobile-first audience?
│  └─ YES → YouTube Shorts (vertical, <60s)
│
├─ High-intent viewers (user-initiated)?
│  └─ YES → In-Feed Video
│
└─ Engagement measurement + reach balance?
   └─ YES → Skippable In-Stream (default)
```

**Video Views campaigns** (no forced-view formats):

```jsx
What's your primary objective?
│
├─ Maximize completed views?
│  └─ YES → Skippable In-Stream (optimize for views)
│
├─ Mobile-first / short-form audience?
│  └─ YES → YouTube Shorts
│
└─ Discovery / high-intent viewers?
   └─ YES → In-Feed Video
```

**Demand Gen campaigns** (no forced-view formats):

```jsx
What's your primary objective?
│
├─ Direct response / conversions?
│  └─ YES → Skippable In-Stream (default)
│
├─ Mobile-first / younger audience?
│  └─ YES → YouTube Shorts
│
└─ Discovery placements?
   └─ YES → In-Feed Video
```

**Performance Max:**

No format selection available. Upload all video formats (horizontal, vertical, square) and all durations (6s, 15s, 30s+). Google selects automatically based on placement and predicted performance.

## Production tips

### Low-budget options

| Approach | Best for |
| --- | --- |
| UGC (user-generated content) | Authenticity, relatable content |
| Phone-shot video | Quick testing, authentic feel |
| Slideshow with music | No video assets, quick MVP |
| Screen recordings | Software/app demos |
| Stock footage + voice-over | Concept testing before production investment |

### High-impact, low-cost techniques

| Technique | Effect |
| --- | --- |
| Strong voice-over | Adds professional feel, reinforces message |
| Music selection | Sets tone, evokes emotion |
| Text overlays | Reinforces key points, aids sound-off viewing |
| Quick cuts | Maintains energy and attention |
| Close-ups | Creates intimacy, works on small screens |

> 💡 **Principle:** Start MVP, invest in winners. Create low-budget versions first to test messaging. Invest in higher production value for proven winners.

## Common mistakes

| Mistake | Problem | Fix |
| --- | --- | --- |
| Slow intro / no hook | Viewers skip before message | Jump straight into action |
| Branding only at end | Skippers never see brand | Brand in first 5 seconds and throughout |
| Too many messages | Confuses viewer, dilutes impact | One clear, focused message |
| Weak or missing CTA | No conversion direction | Clear, specific, audio-reinforced CTA |
| Horizontal only | Misses mobile inventory | Create vertical and square versions |
| Small text / low contrast | Unreadable on mobile | Big text, high contrast, test on phone |
| Feature-focused | Doesn't resonate emotionally | Show how life improves with product |
| Only one video length | Misses format opportunities | Create 6s, 15s, and 30s+ versions |
| No sound design | Misses audio engagement | Use music, voice-over, sound effects |
| Video enhancements enabled | Poor quality auto-generated content | Disable and create formats yourself |
| Wrong campaign for format | Non-Skippable in Demand Gen (not available) | Check format availability matrix first |
